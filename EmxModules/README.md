## 关于EmxModules
&emsp;&emsp;EmxModules模块是EmxEMB2.0的模块层实现，包含了众多通用性较强的小模块详细参考《EmxModules模块设计使用说明》
>注意：所有的修改需要在开发分支上进行，master分支仅用来合并后的版本发布
## 版本命名规则
x.y.z

x:大版本，当modules里面的模块对外提供的接口与之前版本不兼容时，此版本号需要+1

y:小版本，新模块或模块有新的接口加入时，此版本号需要+1

z:修订版本，当模块内部有bug修复，对外不存在接口语义和业务逻辑的修改时，此版本号需要+1</br>

>注意：当上一级的版本号变更后，后一级的版本号需要清零

## 版本发布步骤
>**每次提交请严格按照此步骤进行**

0.提交当前开发分支的修改内容

1.当前处于开发分支，拉取合并master分支的最新提交，如果有冲突，进行冲突解决，并做固件验证

2.切换到master分支，合并之前的开发分支

3.整理与上次版本发布tag之间的所有更改，并编辑`change.log`

5.确保git没有tracking不相干的文件或非必要文件

6.提交修改 `MOD:更新版本`

7.创建tag，遵循版本命名规则，以版本号命名如2.3.1，不需要加字符v

8.push commit 和 tag
